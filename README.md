# Student-Placement-Analytics-Prediction
Developed a Student Placement Analytics &amp; Prediction System using Python and Machine Learning to analyze factors affecting placement outcomes. Performed data cleaning, EDA, and visualization on CGPA, skills, internships, and projects. Built a prediction model and interactive Stream-lit dashboard for data-driven placement insights.


## 📌 Project Overview

The Student Placement Analytics & Prediction System is a Data Science and Machine Learning project designed to analyze the factors that influence student placement outcomes.

The project analyzes academic performance, internships, projects, certifications, aptitude scores, soft skills, extracurricular activities, and placement training to identify their relationship with placement outcomes.

It also includes a Machine Learning model and an interactive Streamlit dashboard for placement prediction and data-driven insights.

---

## 🎯 Objectives

- Analyze factors affecting student placement outcomes
- Perform data cleaning and exploratory data analysis (EDA)
- Identify relationships between student attributes and placement status
- Visualize important placement-related patterns
- Build a Machine Learning model to predict placement status
- Provide an interactive dashboard for placement analysis and prediction

## 🤖 Machine Learning

The project uses a classification-based Machine Learning approach to predict whether a student is likely to be:

- Placed
- Not Placed

The model is trained using student academic, skill-based and professional attributes.
